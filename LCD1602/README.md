
# MSPM0G507 LCD Library

This library for the Liquid Crystal Display 16x2, made to work with the MSPM0G507. 


## Current Features
- LCD Initialization
- LCD Send String/Text
- LCD Cursor Enable or Disable
- LCD Blink Enable
- LCD Display On or Off
